# 自用資料與歷年紀錄設計

## 目標
讓紀錄者姓名、園所、班級、期間與年齡層都可修改並自動保存，同時提供不需登入的歷年學期封存。

## 行為
- 紀錄者姓名同步到頂部工作區、頭像、側欄、報告預覽、Word 與家長 HTML。
- 班級頁集中修改姓名、園所、班級、期間、年齡層與幼兒名單。
- 「封存目前學期」保存完整快照；同一園所、班級與期間再次封存時更新原快照，不重複新增。
- 歷年卡片顯示孩子、照片及觀察數量，並可下載完整 JSON 備份。
- 舊版瀏覽器資料載入時自動補上紀錄者姓名與空白歷年清單。

## 隱私界線
網站網址可公開開啟，但所有個人、幼兒、照片與歷年資料只存在使用者當下的瀏覽器。沒有帳號與伺服器，因此不提供即時跨裝置同步或真正的存取權限控制。

## 驗收
- 單元測試涵蓋舊資料補欄位、紀錄者署名、完整封存及重複封存更新。
- 瀏覽器實測可改名、同步頭像／工作區、建立歷年卡片及下載有效 JSON。
- 390px 手機無水平溢出，正式網址與資產回傳 HTTP 200。
