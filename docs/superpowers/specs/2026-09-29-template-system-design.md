# 芽記模板系統設計

## 目標
在既有免登入個人版中加入可選、可改、可自行輸入的活動、觀察、學習指標與成長報告模板；所有資料仍保存在瀏覽器，不使用外部 AI。

## 功能
- 報告提供「經典紀錄、照片故事、學期總結」三種版型，切換後立即預覽。
- 活動名稱可從常用活動挑選，也可直接輸入自訂名稱；領域可選或自訂。
- 觀察類型可選「行為、語言、合作、探索、生活自理、情緒表達」，關鍵字與整理後文字保持可編輯。
- 學習指標可從常用清單挑選，也可直接輸入，並能從個別孩子的報告移除。
- 報告的標題與引言可直接修改；模板只提供起點，不鎖定文字。
- 個別孩子可輸出 PDF、Word、家長分享 HTML；全班可批次下載 ZIP，內含每位孩子的 Word 與 HTML。

## 資料與相容性
- 模板目錄是唯讀程式資料；使用者選擇寫入 `reportSettings`、觀察紀錄與個別孩子的 `indicators`。
- 既有 localStorage 資料載入時自動補上新欄位，不清除照片、姓名或觀察紀錄。
- HTML 分享檔不含登入或追蹤功能；使用者自行傳送下載檔。

## 錯誤處理
- 空白活動、觀察或指標不保存。
- 批次輸出任一孩子失敗時中止並顯示錯誤，不產生不完整 ZIP。
- 報告無照片或無觀察時仍能輸出，並顯示清楚的空資料文字。

## 驗收
- 單元測試涵蓋模板目錄、舊資料補齊、觀察類型文字、指標新增／移除與報告 HTML。
- 桌面、平板、390px 手機皆可選模板及輸入自訂文字，無水平溢出。
- 正式 GitHub Pages 網址回傳 200，且實際瀏覽器無錯誤。
