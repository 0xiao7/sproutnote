# SproutNote PWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make SproutNote installable and offline-capable on phone, tablet, and desktop while keeping the existing GitHub Pages URL and local-only data model.

**Architecture:** Add a static manifest, PWA icons, and a base-path-aware service worker under `public`. Register it from the React entry point and expose one install action that uses the native prompt where available and clear manual instructions otherwise.

**Tech Stack:** React 19, Vite 6, service workers, Web App Manifest, Node test runner, GitHub Pages.
