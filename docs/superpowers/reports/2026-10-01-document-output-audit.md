# 文件輸出實測紀錄（2026-10-01）

## 驗證方式

以 14 份使用者提供的 DOCX 作私人參考，不複製到公開專案；用 12 位虛構幼兒與安全測試照片產生網站目前 13 種 DOCX。檢查 DOCX 可讀性、紙張、表格與影像結構，並轉 PDF 核對頁數；以 macOS Quick Look 抽看中文與圖文版面。私人來源姓名與照片未納入測試產物、程式碼或本紀錄。

## 結果

| 類別 | 已驗證 | 與來源仍有差距 |
|---|---|---|
| 一般聯絡本 | A3 橫式、短內容 12 格；文字較長／照片或連結較多時減格 | 原始附件有 A3 直式、A4 直式與 A3 橫式混用；依使用者新規則統一 A3，卡內的小欄及文字樣式未逐一重建 |
| 月底課程分享 | A3、4 或 6 格；12 人、每人兩張照片與長文字的實際輸出為 3 面／每面 4 格 | 原檔照片靠左、文字環繞；目前照片並排，圖文流向不同 |
| 全園活動計畫 | A4、可編輯月份／活動／領域 | 來源有兩張大型三欄表，現為一張簡化表 |
| 大肌肉計畫 | A4、七欄月份矩陣 | 來源列數與項目內容須由使用者補齊，非原檔內容預填 |
| 社區踏查 | A4、目標、踏查流程與通知可輸入 | 來源六張表與多頁工作分配，現為兩張簡化表 |
| 教學紀錄 | A4、觀察、照片、省思可編輯 | 來源四張表、幼兒輔導及反思分區，現未完整重建 |
| 形成性評量 | A4、評量項目與三種等第 | 來源兩張表、附加欄位與多頁配置未完整重建 |
| 總結性評量 | A4、三階段評量 | 來源主表六欄含「說明」，現有主表五欄；家長說明與視覺層級不同 |
| 月份活動規劃 | A4、五個星期欄位 | 來源是大格週表加底部備註區，現為較緊密的文字列 |
| 一日作息與協同分工 | A4、時間及五日安排 | 來源含多老師主責／協同與合併欄，結構為 13 欄；現為六欄簡化表 |
| 通知單 | A4、內容與回條 | 可產出；尚未逐項驗證原檔切線與回條位置的列印一致性 |

## 判定

目前可作為可編輯的同類型文件產生器，**尚不能宣稱與 14 份原始文件等同或可直接替代原校表單**。尤其社區踏查、教學紀錄、總結性評量、一日作息的欄位與版型缺口具有實務影響。此次已修正月底課程分享「預計四格、實際兩格」的分頁錯誤，並以相同測試資料重測。

Microsoft Word 與實體 A3／A4 印表機的最後列印效果未在本次驗證；LibreOffice PDF 轉換環境有中文字型缺字現象，因此中文字可讀性另外用 macOS Quick Look 檢查，不把有缺字的 PDF 預覽當成字型驗收。
